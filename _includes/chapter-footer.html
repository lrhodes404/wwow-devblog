On scope. The WoW bots on this blog run on a private, self-hosted VMaNGOS server with a legacy 1.12.1 client, and the other games' bots run only against private server emulators or offline single-player installs. None of it runs on retail. Nobody is competing with these bots for anything; they exist to be watched and studied. The project began as a fork of Drew Kestell's BloogBot, and the about page has the rest of the scope and the credits.
